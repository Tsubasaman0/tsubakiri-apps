# Claude Code 迷わない案内所

AIコーディングツール(Claude Code)を初めて使う人向けの解説サイト。
公開URL: https://cc-guide.kachikan-shindan.workers.dev

## 何に困っていたか
自分が始めたとき、入口が分かりにくかった。ターミナルを使わずに始めたい人向けの案内が無かった。

## 何を決めたか
「今日やる3つのこと」だけを順に案内する。画像を必ず付ける。難しい言葉を使わない(書き方の5ルールを自分で決めた)。

## どう確かめたか
Codexで下書き → Claudeで直し → 自分で手順どおりに操作して詰まる所を直した。有料版(note)も同じ手順で作った。

## AIとの分担
実装・文章の下書きはAI。構成、5ルール、実機での手順確認は自分。
