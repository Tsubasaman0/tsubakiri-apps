# スクショ自動記録ツール 使い方

やること（つばさくんの依頼どおり）:

1. 出力フォルダを新しく作る
2. 「何回やるか」を聞く
3. Mac本体のスクリーンショットを撮って、そのフォルダに保存
4. ブラウザの決まった座標をクリック
5. 3と4を、入力した回数ぶん繰り返す

## 使う前に：許可を2つ出す（最初の1回だけ）

このツールは「画面を撮る」「マウスでクリックする」を自動でやるので、
Mac のセキュリティ機能に2つ許可を出す必要があります。

**システム設定 → プライバシーとセキュリティ** を開いて、以下の2つに
`ターミナル`（Terminal.app）のチェックを入れてください。

- **画面収録**（スクリーンショットを撮るため）
- **アクセシビリティ**（自動でクリックするため）

一覧に `ターミナル` が出ていない場合は、先に一度このツールを実行してみると
自動で許可のポップアップが出ることがあります。出たら「許可する」を選んで、
その後もう一度ツールを実行してください。

## 使い方

1. `スクショ自動記録を起動.command` をダブルクリックする
   （初回だけ「開いてもよいか」聞かれることがあります → 「開く」を選ぶ）
2. ターミナルの黒い画面が開く
3. **クリック位置を記録**（初回、または座標を変えたいとき）
   - 「クリックしたい場所にマウスを置いて Enter」と言われるので、
     ブラウザの押したいボタンなどにマウスを移動して Enter を押す
   - 3・2・1 とカウントダウンした瞬間の位置が記録される
4. **撮影範囲を決める**（初回、または範囲を変えたいとき）
   - `[Enter]` を押すと画面全体を保存する
   - `r` を押すと範囲を指定できる。保存したい範囲の
     **左上の角** → Enter →カウントダウン、続けて
     **右下の角** → Enter →カウントダウン、の順でマウスを置く
   - 一度記録すると、次回からは「クリック位置」「撮影範囲」両方を自動で使い回す
     （聞かれたら `[Enter]`＝そのまま使う／`c`＝クリック位置だけ記録し直す／
     `s`＝撮影範囲だけ記録し直す／`b`＝両方記録し直す）
5. **回数を入力**（例：`10`）
6. **取り込むものの名前を入力**（例：`イシキカイカク`）
   - これがMarkdownのファイル名になる。**NotebookLMに入れたときのソース名**になるので、
     本のタイトルなど、後から見て何の資料か分かる名前にする
   - そのままEnterを押すと、これまで通り日時の名前になる
7. あとは自動で
   「スクショを撮る → 待つ → クリックする → 待つ」
   を、入力した回数ぶん繰り返す
8. 終わったら、続けて自動で **pdf2md アプリの OCR** にかけて、
   全ページをまとめた Markdown を作る
9. **「PNGを消していいか」だけ聞かれる**
   - そのままEnter → 画像を消して、Markdownだけ残す（ふつうはこちら）
   - `n` + Enter → 画像も残す
10. `出力/Markdown/` フォルダが Finder で開く

## 保存先

できあがったMarkdownは、**すべて1か所にまとまります。**

```
musubi-apps/screenshot-clicker/出力/
  Markdown/
    イシキカイカク.md
    ○○の本.md
```

**このフォルダの中身を、そのままNotebookLMにドラッグすれば読み込めます。**

撮影中のPNGは日時フォルダ（例：`2026-08-24_15-30-00`）に一時的に入りますが、
Markdownができた時点で、確認のうえ画像ごと片付けます。
画像を残す選択をしたときだけ、日時フォルダがそのまま残ります。

### なぜ画像を消すのか

1冊で100〜200枚、1回あたり100MB前後になります。
ここはObsidianのVault（iCloud同期）の中なので、そのままだとiCloudの容量を食い続けます。
文字にしてしまえば1冊100KB程度なので、Markdownだけ残す方が扱いやすい、という判断です。

⚠️ **Markdownを確かに書き出せたことを確認してからでないと、画像は消しません。**
OCRに失敗したときは画像がそのまま残ります。

## NotebookLM に渡すために、していること

読み取った文字はそのままだと読みにくいので、軽く整えてから保存しています。

- 先頭に **タイトル・取り込み日・ページ数**を付ける（NotebookLMが出典を説明しやすくなる）
- OCRが入れてしまう変な空白を詰める（`第 1 章` → `第1章`、`2019 年` → `2019年`）
- ページ番号だけの行、罫線のかすのような行を落とす
- 空行が3つ以上続いたら2つにする

**本文の文字は削りません。** 実際に202ページの本で試して、消えた行は0でした。
`テスト.command` をダブルクリックすると、この掃除が正しく動くか検算できます。

## Markdown変換について

スクショが撮り終わったら、隣にある `musubi-apps/pdf2md/` アプリの
`PNGフォルダ→Markdown.command`（macOS標準のVisionという機能で文字を読み取る、
ネット接続不要の仕組み）に自動でかけています。

- `pdf2md` フォルダごと動かしたり消したりすると、この自動変換ができなくなります
  （見つからない場合は「画像だけ残っています」と表示され、スキップされます）
- 文字認識の精度は画像の解像度・文字の大きさによって変わります。うまく
  読み取れないときは、範囲やスクショの大きさを見直してみてください

## 途中で止めたいとき

ターミナルの画面で `Ctrl + C` を押すと止まります。

## 注意点

- クリックする座標は「画面上の絶対位置」を覚えているだけです。
  ブラウザのウィンドウの位置やサイズ、ズーム倍率を変えると、
  違う場所をクリックしてしまうので、その場合は座標を記録し直してください
  （`r` を選ぶ）。
- クリック中は本物のマウスクリックとして動くので、実行中は
  他の操作をしないでください（別のウィンドウをクリックしてしまう等の
  誤動作のもとになります）。
- 座標は `config.json` に保存されています。消せばまた最初から
  記録し直しになります。
