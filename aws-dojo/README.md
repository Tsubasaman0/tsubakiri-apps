# AWS道場

AWS Certified Cloud Practitioner の勉強を「続く仕組み」にするための、自分専用の稽古場。
公開URL: https://aws-dojo.kachikan-shindan.workers.dev

## 何に困っていたか
資格の勉強が続かない。スキマ時間にスマホでやりたい。夜は目が疲れて読めない。

## 何を決めたか
5問ずつ／間違えた問題だけ翌日に戻る／寝る前に聞くだけの音声、の3つに絞った。用語は「名前を作っている英単語」から覚える方式にした。

## どう確かめたか
- 問題帳(180問)はClaudeに作らせ、別会社のAI(Codex)とGeminiに事実を検収させて、指摘を反映した。最終判断は自分
- 問題の偏り、保存データが消える不具合は、自分で使って見つけて直させた
- `test.js` で音声の「今日の分」まわりを自動テスト

## AIとの分担
実装はAI(Claude)。私は「何を作るか決める・動かして確かめる・直させる」。毎日18時に15問と音声が自動で増える仕組みは、Codexが問題を作りClaudeが検収する形で回している。

## このリポジトリに入っていないもの
音声ファイル(`public/audio/`、約30MB)と生成スクリプトは容量と権利の都合で入れていない。
